# 実行サンプル (Examples)

本ディレクトリには、ベンチマーク実行用のサンプルキーマップ定義ファイルを格納しています。

---

## 収録サンプル

1. **`sample_qwerty_romaji.json`**:
   デファクトスタンダードである QWERTY ローマ字入力の定義です。
2. **`sample_jis_kana.json`**:
   JIS X 6002 標準かな入力（4段単打＋濁点/半濁点後置）の定義です。

---

## 実行例

リポジトリ直下で以下のコマンドを実行すると、`data/keymaps/` に配置されたサンプルの評価が実行されます。

```bash
uv run python main.py
```
